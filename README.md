# Checkers Pro — Tournament AI

Версия с существенно усиленным движком.

## Уровни
1. Новичок — быстрый.
2. Сильный — заметно глубже.
3. Мастер — глубокий поиск.
4. Гроссмейстер — до ~12 секунд расчёта.
5. Турнирный — до ~22 секунд расчёта.

Движок использует iterative deepening, Principal Variation Search, alpha-beta, transposition table, killer/history move ordering, quiescence search и расширенную позиционную оценку.

Важно: это сильный программный соперник, но нельзя честно гарантировать уровень человеческого чемпиона или совершенную игру. Для полного совершенства нужен специализированный endgame/tablebase слой.
